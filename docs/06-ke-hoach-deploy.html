06 · Kế hoạch deploy

Đưa game lên Google Cloud qua tên miền [domain], chỉ dùng gói miễn phí (Free Tier). Đây là kế hoạch, chưa chạy lệnh nào.

Tóm tắt
  • Hạ tầng: 1 máy ảo Compute Engine e2-micro ở us-central1, đĩa standard 30 GB, IP tĩnh, chạy Docker Compose hiện có + thêm 1 dịch vụ Caddy lo HTTPS.
  • RAM 1 GB: thêm 2 GB swap; giới hạn RAM: database 256 MB, app 192 MB, Caddy 96 MB.
  • Mở ra Internet: chỉ cổng 80 và 443. Database và cổng 3000 không mở ra ngoài; SSH chỉ cho dải IP của Google.
  • Chi phí: 0 đồng nếu đúng cấu hình. Các khoản có thể phát sinh và cách tránh ở mục 4.
  • Lưu ý lớn nhất: tài khoản đang dùng thử (còn ~83 ngày). Hết dùng thử mà không nâng cấp thì máy bị dừng và xoá sau 30 ngày — kể cả phần miễn phí (mục 4.2).

Đã duyệt ngày 18/11/2026: tên miền game.dingdang.io.vn (tên miền con của dingdang.io.vn, mua ở PA Việt Nam — tên miền con không mất thêm phí); project riêng; chỉ dùng phần miễn phí, không nâng cấp tài khoản trả phí.

Tự động hoá: bước 7–11 do file deploy/gce-startup.sh tự làm mỗi lần máy ảo khởi động (swap, Docker, lấy code vào /opt/dapchuot, tạo .env, chạy Docker Compose). Tiến trình xem ở VM → Serial port 1, các dòng bắt đầu bằng DAPCHUOT:. Các lệnh ở bước 7–11 vẫn giữ để hiểu và để làm tay khi cần.

Thay [domain] bằng tên miền thật (VD dapchuot.example.vn) ở mọi chỗ trong trang. Cần có quyền sửa bản ghi DNS của tên miền đó tại nơi mua tên miền.

1 · Sơ đồ

Dịch vụ app và db giữ nguyên như Docker Compose hiện có. Khi deploy chỉ thêm file docker-compose.prod.yml (thêm Caddy, giới hạn RAM, xoay vòng log, bỏ cổng 3000 ra ngoài) và file Caddyfile — nội dung ở mục 3, bước 9.

3 · Các bước deploy và cách kiểm tra

Bước 1–6 làm trên trang Google Cloud Console (console.cloud.google.com). Bước 7 trở đi gõ lệnh trong cửa sổ SSH của máy ảo. Mỗi bước có ô Kiểm tra: chỉ làm bước sau khi bước trước đạt.

1Tạo project riêng và gắn tài khoản thanh toán

Console → chọn project ở thanh trên → New project → tên dap-chuot. Sau đó Billing → Link a billing account → “My Billing Account”. Vào Compute Engine → bấm Enable để bật Compute Engine API.

Kiểm tra: trang Billing → Account management → Projects thấy dap-chuot gắn “My Billing Account”; trang Compute Engine → VM instances mở được, danh sách trống.

2Đặt cảnh báo ngân sách

Billing → Budgets & alerts → Create budget: phạm vi project dap-chuot, số tiền 25.000 ₫, cảnh báo ở 50%, 90%, 100%, gửi email cho bạn. Bỏ tick “Include credits” để thấy cả phần đang trừ vào tín dụng dùng thử.

Kiểm tra: budget hiện trong danh sách. Lưu ý: budget chỉ báo, không tự dừng chi tiêu.

3Giữ một IP tĩnh

VPC network → IP addresses → Reserve external static IP address: tên dapchuot-ip, IPv4, Network tier Premium, Type Regional, Region us-central1. Làm bước 4 ngay sau đó (IP để không lâu sẽ bị tính phí).

Kiểm tra: thấy dapchuot-ip và địa chỉ số (VD 34.x.x.x). Ghi lại địa chỉ này.

4Tạo máy ảo

Compute Engine → VM instances → Create instance:

  • Name dapchuot-vm; Region us-central1; Zone us-central1-a.
  • Machine: series E2, type e2-micro.
  • Boot disk → Change: Debian (bản mới nhất), disk type Standard persistent disk, size 30 GB.
  • Firewall: tick Allow HTTP traffic và Allow HTTPS traffic.
  • Networking → network interface default → External IPv4 address: chọn dapchuot-ip.

Kiểm tra trước khi bấm Create: khung ước tính giá bên phải có dòng kiểu “Your first 744 hours of e2-micro instance usage are free this month” và đĩa ghi Standard. Sau khi tạo: máy có dấu xanh, cột External IP đúng địa chỉ ở bước 3.

5Thu hẹp SSH, bỏ cổng không dùng

VPC network → Firewall:

  • Sửa luật default-allow-ssh: Source IPv4 ranges đổi từ 0.0.0.0/0 thành 35.235.240.0/20 (dải Google dùng cho nút SSH trên Console).
  • Xoá luật default-allow-rdp (cổng 3389, dành cho Windows, không dùng).

Kiểm tra: danh sách còn mở ra Internet chỉ có default-allow-http (80), default-allow-https (443), default-allow-icmp; bấm nút SSH của máy ảo vẫn vào được. Nếu SSH không vào được → tạm trả luật về 0.0.0.0/0, làm tiếp, rồi xem lại ở mục 6.

6Trỏ tên miền về IP tĩnh

Tại trang quản lý DNS của nơi mua tên miền (không dùng Cloud DNS của Google vì có tính phí): tạo bản ghi A, tên [domain] (hoặc @), giá trị = IP tĩnh, TTL 300.

Kiểm tra: trên máy bạn mở PowerShell gõ nslookup [domain] → ra đúng IP tĩnh. Có thể mất vài phút đến vài giờ.

7Bật 2 GB swap

Bấm SSH ở máy ảo, rồi chạy:

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
echo 'vm.swappiness=10' | sudo tee /etc/sysctl.d/99-swap.conf
sudo sysctl --system

Kiểm tra: free -h → dòng Swap: tổng 2.0Gi. Khởi động lại máy (sudo reboot), SSH lại, free -h vẫn còn 2.0Gi.

8Cài Docker, Git và tự cập nhật bảo mật
sudo apt-get update
sudo apt-get install -y ca-certificates curl git unattended-upgrades

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/debian $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

Kiểm tra: docker compose version ra số phiên bản; docker run --rm hello-world in “Hello from Docker!”; systemctl is-enabled unattended-upgrades ra enabled.

git clone https://github.com/dtleeha/vibecoding.git

Hai file sau sẽ được thêm vào repo trước khi deploy (chưa tạo — chờ duyệt kế hoạch):

Caddyfile

{$DOMAIN} {
    encode zstd gzip
    reverse_proxy app:3000
    header {
        Strict-Transport-Security "max-age=31536000"
        -Server
    }
}

docker-compose.prod.yml (ghép thêm vào docker-compose.yml hiện có)

services:
  app:
    ports: !reset []            # không mở cổng 3000 ra ngoài
    expose: ["3000"]
    mem_limit: 192m
    logging: &log
      driver: json-file
      options: { max-size: "10m", max-file: "3" }

  db:
    mem_limit: 256m
    command: ["postgres",
      "-c", "shared_buffers=32MB", "-c", "max_connections=20",
      "-c", "work_mem=2MB", "-c", "maintenance_work_mem=16MB",
      "-c", "effective_cache_size=128MB"]
    logging: *log

  caddy:
    image: caddy:2-alpine
    ports: ["80:80", "443:443"]
    environment:
      DOMAIN: ${DOMAIN:?Thiếu DOMAIN trong .env}
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - caddy_data:/data
      - caddy_config:/config
    depends_on: [app]
    mem_limit: 96m
    logging: *log
    restart: unless-stopped

volumes:
  caddy_data:
  caddy_config:

Kiểm tra: ls thấy docker-compose.yml, docker-compose.prod.yml, Caddyfile, thư mục app, server, admin.

docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build

12Kiểm tra từ bên ngoài

  • Mở http://[domain] → tự chuyển sang https://.
  • Mở https://[domain]/admin → trang đăng nhập.

Kiểm tra: chạy lại các ca TC31, TC37, TC46, TC52, TC58 (cookie có Secure), TC65 trong 05 · Kế hoạch test trên link thật.

  • Điền nội dung thật cho “Thông báo xử lý dữ liệu” (đang để chỗ trống) — xem 04 · 4.15.
  • Xoá dữ liệu thử (nếu có).

Kiểm tra: trên form đăng ký bấm “Thông báo xử lý dữ liệu” → không còn chữ “[Nội dung do chủ dự án cung cấp]”.

14Sao lưu và theo dõi chi phí (định kỳ hằng tuần)
docker compose -f docker-compose.yml -f docker-compose.prod.yml exec -T db \
  sh -c 'pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB"' | gzip > ~/backup-$(date +%F).sql.gz

Tải file về bằng nút Download file trong cửa sổ SSH. File chứa thông tin cá nhân: cất nơi an toàn, xoá khi không cần.

Kiểm tra: Billing → Reports, lọc project dap-chuot, nhóm theo SKU: sau 24–48 giờ đầu, mọi dòng phải có chi phí ròng 0 ₫ (dòng nào khác 0 → xem mục 4). df -h / còn trống trên 50%.

4.2 · Dùng thử và gói miễn phí là hai thứ khác nhau

  • Tài khoản thanh toán hiện đang dùng thử: còn ~7,75 triệu ₫ tín dụng và ~83 ngày (đã kiểm tra ngày 18/11/2026). Dùng trong giới hạn Free Tier thì không trừ tín dụng.
  • Hết dùng thử mà không nâng cấp: thanh toán bị tắt, máy ảo bị dừng → web ngừng chạy; sau 30 ngày tài nguyên bị xoá vĩnh viễn.
  • Nâng cấp lên tài khoản trả phí thì máy tiếp tục chạy miễn phí trong giới hạn Free Tier; nhưng mọi khoản vượt giới hạn sẽ trừ vào thẻ.
  • Kết luận: nếu khoá học kết thúc trước khi hết dùng thử → không cần nâng cấp, xoá sạch theo mục 5. Nếu cần chạy lâu hơn → quyết định nâng cấp là của bạn.
5 · Xoá sạch sau khoá học
  1. Sao lưu nếu cần (bước 14) hoặc xuất CSV từ trang admin. Sau đó thông báo/xử lý dữ liệu người chơi theo nội dung đã cam kết.
  2. Xoá máy ảo: VM instances → chọn dapchuot-vm → Delete (đĩa khởi động bị xoá cùng).
  3. Giải phóng IP tĩnh: VPC network → IP addresses → dapchuot-ip → Release static address. Đây là bước hay bị quên nhất.
  4. Gỡ bản ghi DNS [domain] tại nơi mua tên miền.
  5. Tắt cả project dap-chuot: IAM & Admin → Settings → Shut down. Google xoá hẳn sau 30 ngày. Không đụng tới các project Gemini.
  6. Kiểm tra thanh toán: 2–3 ngày sau, Billing → Reports không còn chi phí cho dap-chuot. Nếu đã nâng cấp tài khoản trả phí và không dùng nữa: Billing → Account management → Close billing account.
  7. Trên máy bạn: xoá các file sao lưu .sql.gz, file .env, file log có thông tin người chơi.

Kiểm tra cuối: Compute Engine không còn máy; IP addresses không còn IP tĩnh; project hiện “Pending deletion”; nslookup [domain] không còn ra IP cũ.
